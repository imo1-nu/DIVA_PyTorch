# happy gain1,1：保存固定評価の事後誤差集計

2026-10-23。ユーザーの「Hフォルマントとfmfitで誤差はどのくらい変わったか」に対応する事後解析。元の/u/事前主評価とhappy聴取用実験を置き換えない。制御・学習・音声の再生成は行わない。

対象は既に保存したhappy gain1,1、ゼロFFから4/20回学習後の固定FF-only/FF+FB全8系列。最後に生成した「DiffWave学習時の保存済み学習済みArtから1回生成」はfmfitだけでH観測の対照がなく、この観測方式比較には混ぜない。

指標定義を誤差の数値集計前に固定する。happyは時変目標なので/u/中央200点は使わない。保存ff_activation（実際に運動FFへ渡されたSSM活動）が非ゼロの全点を使い、活動と元Aud_min/maxとの積で同時刻の目標帯を取得する。構造確認では全方式・生成で同じ99点（program index1–99、5–495ms）。先頭未活動点と終了後の未活動点は別記して除く。範囲は結果に合わせて調整しない。

独立NumPyの輪郭→面積→Hでrawからピークを再計算し、両方式に共通のHピークの目標帯外距離Hz（成分別と3成分平均）を評価する。fmfit観測時のM対目標距離、同じrawのH−Mの絶対差も別指標として保存する。Hは波形フォルマント・真の極周波数と区別する。

欠測は距離0や達成扱いにしない。全99点を分母にした有効率・帯内率を報告し、距離は有効点平均と明記する。新モードの有効率が低下する場合は距離低下だけで改善判定しない。各対照で両方が全3成分有効な共通時点に限定した距離差も併記する。厳密帯内率と<=.1Hzの数値許容差率を保存する。体性帯外SSEも同じ99点で計算する。

入力NPZ、target/asset、解析コード・参照コードのSHAと環境を保存。入力ファイルの前後SHAが不変で、独立ピークと元のnativeログの差・有効性不一致も記録する。閉鎖時刻の違いを補間で隠さない。
