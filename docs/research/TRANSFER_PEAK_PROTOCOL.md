# TRANSFER-PEAK-01 事前プロトコル

2026-10-23。実装・数値比較前にGitHub Issueへ登録する。

## 仮説
同じraw調音指令の静的伝達関数Hの先頭3ピークを聴覚FBへ返すと、従来fmfit観測より独立Hピークの目標帯外距離が減る可能性がある。既存逆写像との不一致、体性感覚との競合、姿勢補正、ピーク順位切替により改善しない競合説明も保持する。

## 方法と固定条件
main 2920c35から別worktree。fmfit（既定）とtransfer_peaksのF1–F3観測だけを比較する。13次元指令、聴覚[F0,F1,F2,F3]の正規化[100,500,1500,3000]、F0、体性感覚8成分、資産、/u/目標、逆写像、姿勢補正、合成器を保持する。保存近似の再学習・波形からのオンライン推定は行わない。

raw→Input.Scale→tanh→輪郭→xy2ab→音声化と同じ面積処理（負を0、0<A<.025のみ.025）→native a2h。fs11025 Hz、n65536、正周波数の20log10|H|、prominence1 dB、最小間隔50 Hz、50–4950 Hz、周波数順の先頭3本。目標やfmfitへの最近傍選択をしない。完全閉鎖・空面積・非有限・ピーク不足を記録し、欠測を達成やfmfitへのフォールバックにしない。

baselineは従来fmfit。隣接研究の既存/u/401点目標をそのままコピーし、両条件ともゼロFF、seed0、既定ゲイン・遅延・学習率。同じ20試行を走らせ4回・20回後に重みを保存し、学習を止めたFF-only/FF+FBを各1回生成する。主集計窓は既存研究と同じ0.5≤t<1.5秒（200点）、全401点も保存する。FF-onlyはfeedback_gain=0のみで既存の他条件を変えない。

## 評価
主評価は固定重み生成の独立再計算Hピークの成分別・全成分平均帯外距離Hz、成分別・全3成分同時帯内率、有効観測率、体性感覚誤差。欠測率と帯内率の分母は全予定観測とし、距離の有効点平均を単独で改善と判定しない。オンライン学習値は別記録。欠測増加時は改善判断を保留。学習改善は実装完了の必須条件にしない。波形一致・自然性・日本語母音の知覚品質は評価しない。
