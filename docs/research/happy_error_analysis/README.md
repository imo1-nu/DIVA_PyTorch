# happy gain1,1：固定評価の事後誤差集計

2026-10-23。ユーザーの誤差量の質問を受け、保存済み軌道だけを集計した事後解析。/u/の事前主評価を置き換えない。再学習・音声再生成はない。

対象はゼロFFから学習したhappy、ゲインFF=1/FB=1、seed0、4/20回後の重み固定生成8系列。最後の「保存済み学習済みArtからDiffWave学習時ソースで1回生成」はfmfitのみなので、比較に含めない。

同時刻の目標は保存された実運動FF入力のSSM活動と元Aud_min/maxとの積から取得した。活動が非ゼロの全99点（program index1–99、5–495ms）を全条件で用いる。先頭の未活動点と終了後の未活動点は除外した。区間は誤差を見る前に構造から固定し、[事後解析の条件](../HAPPY_ERROR_ANALYSIS_PROTOCOL.md)をIssue #34へ登録した。

主指標はraw→独立NumPy輪郭→面積→Hから再計算した静的ピークの目標帯外距離Hz。両観測方式を同じH指標で評価し、fmfit自身の近似誤差で置き換えない。波形フォルマントや極周波数の測定ではない。

## 固定FF+FBの結果

距離は有効観測点での平均。有効率・厳密帯内率の分母は欠測を含む全99点。

|学習|観測方式|第1/第2/第3ピーク 平均帯外Hz|3成分平均Hz|全3成分有効率|全3成分同時帯内率|体性SSE|
|---:|---|---|---:|---:|---:|---:|
|4|fmfit|107.156 / 0.000 / 227.827|111.661|88.89%|0.00%|0.067973|
|4|transfer_peaks|90.109 / 11.810 / 120.742|74.220|83.84%|0.00%|0.066950|
|20|fmfit|35.103 / 18.943 / 200.048|84.698|79.80%|0.00%|0.007474|
|20|transfer_peaks|34.635 / 13.996 / 19.246|22.626|79.80%|0.00%|0.009681|

20回後は84.698→22.626Hz、73.29%減。有効率は両方79/99点=79.80%で共通時点も同じ。主な低下は第3ピーク200.048→19.246Hz（約90.38%減）。第1ピーク35.103→34.635Hzはほぼ変化がない。第2ピーク18.943→13.996Hzは低下した。全3成分同時帯内率は両方0%のまま。体性SSEは.007474→.009681へ増加（約29.53%）した。Hの距離減少だけで全目標達成や音質改善と判定しない。

4回後の有効点平均111.661→74.220Hzには、有効率88.89%→83.84%の低下を伴う。この約33.53%減をそのまま改善率とはしない。両方式で全3成分が有効な共通83時点にそろえると97.818→74.220Hz、24.12%減。ただし新方式で測定不能が増えた事実も残る。

## 同じ姿勢での2経路の値の違い

制御後の目標誤差とは別に、各軌道の同じrawに対するHピークとfmfit値の平均絶対差を計算した。閉鎖等でHが無効の時点を除く。これは人間の真値に対する予測誤差を意味しない。

|学習|観測方式|H−fmfit絶対差の平均 F1/F2/F3 Hz|
|---:|---|---|
|4|fmfit|131.649 / 220.157 / 488.154|
|4|transfer_peaks|72.608 / 230.503 / 320.345|
|20|fmfit|31.223 / 125.913 / 401.823|
|20|transfer_peaks|27.751 / 89.797 / 93.863|

fmfitで学習した20回後でも、fmfit自身では第3成分の帯外距離0Hzだが、同じ軌道のH第3ピークは平均200.048Hz帯外だった。近似モデルの内部達成と静的Hピーク達成は別である。新観測はfmfit係数を再学習していないため、H−M差の変化を近似モデル自体の改善とは呼ばない。
